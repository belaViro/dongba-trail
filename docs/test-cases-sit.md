日期：2026-09-24。范围：DATA-01/03/04、USER-01、PRIVACY-01、MERCHANT-01、COUPON-01/02、QUEST-01/02、GEO-01、AUTH-02。

## 执行约定

- 用例编号：`TC-模块-三位序号`；数据编号：`SIT_V1_模块_三位序号`；展示名称：`【SIT-模块-三位序号】场景名称`。
- 模块：DCT 字典、MCH 商户、POI 点位、PRD 商品、CPN 优惠券、ACT 活动、QST 路线、NOD 节点、SMP 样本、REV 修订、VAL 输入校验。
- 优先级：P0 核心数据/权限/删除；P1 主要业务；P2 展示。结果只允许 PASS、FAIL、BLOCKED、NOT_RUN。
- 合成图片带 `SYNTHETIC SOFTWARE TEST` 标记，不是真实东巴字；来源明确为 `synthetic:SIT_V1`。不得用于真实文化发布、商户推广、模型准确率报告。
- 默认前置条件：管理员登录测试部署，执行导入脚本；测试数据与真实记录通过前缀区分。不得对全部用户运行清理，不得修改原有记录。
- 脚本默认 dry-run；需要显式 `--apply --allow-published-test-data --confirm-database <库名>`。导入仅通过本机 API；临时会话执行后撤销，不创建或重置账号。
- 首次导入53条：字典12、商户6、点位6、商品8、优惠券8、活动5、路线3、节点5。重复导入跳过已有固定ID，不刷新日期、不覆盖人工修改。
- 时间用例按首次导入UTC生成：正常为前1天至后90天；未开始为后30天至后90天；过期为前90天至前1天。日期会自然到期，不能把再次执行当成重置测试环境。
- 本文是测试设计，不是通过证明。实际结果见 [执行证据](evidence/sit-v1.md) 和逐项JSON报告；未执行的用例保持 NOT_RUN。
