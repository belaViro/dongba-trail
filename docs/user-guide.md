# 业务使用指南

本指南对应已实现的小程序、运营工作台和商户工作台。首次使用先按 [README](../README.md) 启动服务；默认不预置虚构字典或门店。模型接口按用户要求保留占位，未接入时识别显示不可用，其他已配置业务可继续使用。

## 运营准备

1. 在工作台首次创建管理员，或通过离线初始化脚本创建。管理员在“账号管理”添加运营账号；商户账号必须关联已经建立的门店。
2. 在“东巴字典”录入词条、分类、文化释义、来源、真实字形图片和多写法。核对内容后审核并发布；没有来源、释义或字形不能发布。
3. 在“商户”“文化地图”等页面建立门店和POI，填写真实GCJ-02经纬度。给门店关联已审核词条，商品和活动也应配置所属商户。
4. 建立优惠券，填写适用规则、总库存、每人限领次数及有效期，再发布。已发出的券不允许任意修改所属商户、有效期或使用规则。
5. 建立寻迹路线与节点，选择识字、扫码、到店围栏、优惠券核销或人工确认。配置奖励券并发布。扫码节点可展示和下载任务二维码，布置到对应门店或地点。

游客只看到已发布内容和当前有效的优惠、活动及任务。门店或内容下架后，相关入口会隐藏或显示不可用。商户修改资料、商品等内容会回到草稿，运营应在审核后重新发布。

## 游客流程

1. 在小程序阅读隐私指引并通过微信登录。微信账号或隐私信息未配置时，页面会明确说明当前不可用。
2. 从首页拍照或选择相册，确认上传。模型接入后查看候选，选择正确词条；没有合适结果时提交文字反馈，等待运营复核。
3. 在文化详情查看释义、来源、同字异形与已配置音频，可以收藏，并查看与该字相关的商户、商品和地点。
4. 查看商户详情，导航到店或领取优惠券；在“我的优惠券”出示券码或二维码，由该商户核销。刷新后查看使用状态。
5. 加入寻迹路线，按节点条件识字、扫码、定位打卡或提交已核销券。人工确认节点由运营处理；完成路线后查看印记和奖励。
6. 选择本人已收藏或确认识别的1至3个已发布词条，生成“我的东巴印记”海报，保存或使用微信分享入口。

奖励暂时无库存时，路线完成状态和印记会保留；补足奖励券后可重试领取。海报没有可用微信分享码时会标记缺失，不会用装饰图形替代。个人中心可查看收藏、识别历史、优惠券和任务，识别历史支持清空。

## 商户流程

使用管理员分配并关联门店的账号登录，系统进入商户工作台。

- “门店资料”维护地址、营业时间、联系电话及图片，提交后等待运营审核。
- “文化标签”查找已发布词条并申请关联，审批结果在申请记录中查看。
- “商品”“优惠券”“活动”管理本门店内容，按审核流程发布或下架。
- “优惠券核销”输入券码，支持的浏览器也可调用相机扫码。系统确认券有效且属于本店后核销。
- “核销记录”和看板查看真实领取、核销、访问、导航及文化来源。重复核销会返回已核销状态。

如登录后没有关联门店，应由管理员修改该账号的门店归属。商户不能修改权威文化释义或自行审批文化标签。

## 运营日常

- 在内容列表检索并维护字典、门店、POI、商品、活动、优惠券和路线，处理待审核内容与商户标签申请。
- 在“反馈复核”查看用户确认及纠错，批准或驳回并填写说明；复核记录不会自动触发模型训练。
- 在任务节点的操作菜单中处理“人工确认打卡”，填写目标游客用户编号。游客可在个人中心或人工节点提示中复制本人编号；其他类型按其配置条件完成。
- 查看识别记录、调用状态和业务看板；模型处于占位状态时，未配置提示是预期结果。
- 在推荐配置中调整六项权重，合计保持100%；商户质量和运营因素由运营维护。
- 在字典及记录页面使用导出功能，按当前搜索和状态下载CSV；导出动作会进入审计记录。

已有游客加入的路线不能继续改变核心节点规则。需要更换玩法时建立新路线，避免参与者进度含义改变。

## 真正运行所需资料

实际对外使用还需真实小程序账号与域名、模型适配和凭据、有授权且经审核的东巴字形与文化内容、真实门店坐标及任务布置。当前软件与隔离测试不会替这些资料作出真实性保证。真机相机、地图、保存和分享验证见 [小程序说明](../miniprogram/README.md)；这些后续平台准备与当前业务功能交付分开记录。
