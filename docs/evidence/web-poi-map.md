# 运营地图接入后端点位与侧栏去水印

日期：2026-09-26；对应 `GEO-01`、`DESIGN-01` 和 D-035。本证据针对**本地源码**，不是公网已部署证明。

## 原因与修正

- 原“丽江文旅点位概览”使用经纬度线性插值在 CSS 装饰背景上绘制点，且混合了商户记录和 POI；无坐标时甚至会任意散点。现在只从后端公开的 `/api/v1/map/pois?limit=100&offset=…` 分页获取已发布文化地图点位，并在 OpenStreetMap 底图上按 GCJ-02→WGS-84 转换标记；标记名称来自接口，不预置景点，也不混入商户。
- 缺失坐标不绘制；接口出错、无已发布点、底图瓦片失败分别提示。后端的 `OPS_` 演示点在详情中明确标识“非实地核验”，不等于实际景点已审核。底图依赖第三方瓦片访问，现阶段未核实中国大陆用户实际网络可用性；如需稳定商用地图仍需确认合规供应商和授权。
- 原 `web/public/art/lijiang-sidebar.png` 从参考图截取时带着“权限管理”“操作日志”“系统设置”字样，叠作背景产生水印；已取消该图的 CSS 引用并改为纯渐变。侧栏改整栏滚动，不再在固定页脚处截断菜单。
