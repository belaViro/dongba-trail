`xl/worksheets/sheet1.xml`、`xl/cellimages.xml` 及其关系文件，把 B 列
`DISPIMG` ID 精确映射到 `xl/media/` 中的原始图片；文件名取同一记录的
中文含义。提取过程直接写出嵌入的 JPEG 字节，不缩放、不重编码。

```powershell
.venv\Scripts\python.exe -
```

提取器在写出前断言：工作簿中的 50 个 B 列 ID 与用户给出的 ID 按顺序
完全一致，且 50 个中文含义均非空并互不重复。
