## 用户反馈与修正

用户反馈“视觉识别模型只有未启用和火山，而且卡片排版太长”。原实现实际已在Element Plus下拉菜单中包含
本地DB1404选项，但未展开时不可见，容易被理解为只有两个选项；系统配置的识别、海报和地图三个长表单又在
同一卡片连续纵向展示。

本轮仅修改Web展示：

- 提供方使用始终可见的三段按钮：未启用 / 本地 DB1404（CPU） / 火山引擎 Ark。
- 顶部使用视觉识别 / 旅游海报 / 文化地图三段切换，一次只显示一段；保存按钮仍统一保存完整配置。
- 当前生效状态改为紧凑标题行，详情双列；本地模型版本与CPU线程双列，窄屏回退单列。
- 保留当前提供方、未保存选择提示、只读本地信息、Ark密钥保留、共用超时和无自动付费兜底语义。
  不改后端、数据库、模型或系统配置，不自动切换提供方。
