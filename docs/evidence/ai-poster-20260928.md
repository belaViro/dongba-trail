# AI旅行海报与系统配置（2026-09-28）

## 范围与依据

- 需求：SHARE-01、OPS-03、DESIGN-01；决策：D-058。
- 用户要求参考图08优化“生成我的东巴印记”，接入第三方AI生图，并加入管理员系统配置。
- 有界任务：旅行海报页面、独立生图适配器、海报任务接口及生图配置。不改识别模型、寻迹业务、运营数据或原始DOCX，不部署公网或上传微信。
- AI只生成不带字形、文案和二维码的丽江风景背景；已收集且已发布的审核字形、用户文案、标题和真实小程序码由服务器确定性合成，避免模型编造字形、文化含义或假二维码。

## 实现与契约

- 原生页面按参考图改为雪山古城页头、白色编辑卡、顺序选字、纸笺/雪山/古城/简约四种风格、50字文案、真实PNG预览与保存/微信原生分享。最多3个已收集字，输出沿用选择顺序；文案在客户端和服务器一致归一化空白。
- `POST /api/v1/share/poster/jobs` 快速返回202，`GET /api/v1/share/poster/jobs/{id}` 查询所有者隔离的任务；请求令牌与内容指纹防止网络重试重复生图，失败不会降级为假成品。排队/运行超过480秒明确失败，不自动重启付费请求。确认终态失败后只有用户主动点击“重新生成”才创建新令牌，页面说明会发起新任务；暂时网络故障始终重试原任务。
- 兼容原同步海报入口，但同样必须成功调用AI；使用现有实体/事件/媒体存储，无数据库迁移。缺失字形资产或配置在付费请求前拒绝。
- 适配OpenAI兼容Images接口，支持Base64或受限公网URL图片，限制响应大小、像素数和图片格式；图片下载不携带供应商Bearer，错误仅返回业务码，不保存原始供应商错误或密钥。
- 管理员新增独立提供方、端点、模型、超时、尺寸、质量、替换/清除密钥，空密钥保留旧值；旧客户端未提交生图字段时不擦除新配置，识别与生图密钥互不覆盖。复用现有Fernet服务器加密主密钥，GET只返回是否已配置。
- “读取可用模型”只请求模型列表，不生成付费图片；修改端点后必须重新输入密钥，避免把旧密钥发送到另一个地址。
- 详细字段和错误见 `docs/contracts/runtime-system-config.md`、`docs/contracts/business-v1.md`；OpenAPI由应用导出。
