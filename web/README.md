# 东巴寻迹 Web 工作台

Vue 3、TypeScript、Element Plus 单应用，运营 `/admin` 与商户 `/merchant` 独立导航、权限和工作流。

## 启动

```powershell
cd web
npm ci
npm run dev
```

默认地址 `http://127.0.0.1:5173`。端口占用时 Vite 自动选择下一个可用端口，以终端输出为准。
开发代理将 `/api` 转发到 `http://127.0.0.1:8010`，后端需单独启动。
集成验收可设置 `DONGBA_PROXY_TARGET` 指向独立测试后端，避免向正常开发数据库写入测试业务记录。

首次访问读取真实 `/auth/setup-status`；满足服务端初始化策略时可创建管理员。随后管理员可以创建商户、关联商户账号与运营账号。
不内置演示数据、账号或模型凭据。不提供浏览器端模型密钥配置。

## 验证

```powershell
npm run typecheck
npm test
npm run build
```

测试覆盖真实客户端的鉴权请求格式、错误传播、会话失效处理、上传类型和表单权限边界。
这些测试使用 HTTP 替身，不代表服务端集成、微信真机或真实模型验收。

## 功能边界

- 运营：字典、异形、文化内容、商户、POI、商品、优惠券、活动、路线、节点、账号管理；内容状态流转；纠错和标签审核；手工节点确认；审计、识别记录、数据看板和推荐权重。
- 商户：资料、商品、优惠券、活动、文化关联申请、优惠券核销、核销记录及来源数据。
- 图片上传使用后端 `/media`，私有草稿图片通过带鉴权请求获得临时 Blob 地址展示。
- 扫码使用浏览器 BarcodeDetector；不支持或摄像头权限拒绝时提供明确状态和手动输入。正式扫码兼容性需在目标设备验证。
- 登录令牌仅保存在当前标签会话的 sessionStorage，后端负责所有最终权限和库存校验。
- 所有数值来自业务 API，未配置模型或空数据不会生成虚假经营统计。
- 运营记录导出由服务端生成 CSV 并记录审计；字典、纠错、识别记录、标签审核和操作日志支持当前筛选导出。
- 扫码任务节点可预览及下载标准二维码 PNG，现场扫码口令与节点绑定。

## 浏览器验收

当前用户试用入口为 `http://127.0.0.1:5318`，连接正常开发服务8010，首次访问创建管理员。
隔离验收入口 `http://127.0.0.1:5317` 连接8011及独立测试库，不能作为真实经营数据来源。
完整浏览器脚本位于 `../tests/e2e/acceptance.mjs`，只允许向隔离端口写入测试记录；生成账号只保存到被忽略的 `runtime/e2e/`。
验收证据见 `../docs/evidence/web-acceptance.md`。

## 部署

`npm run build` 输出 `dist/`。Web 服务器需对客户端路由提供 `index.html` 回退，并将 `/api/` 反向代理到后端。生产要求 HTTPS；禁止将模型、微信等服务密钥注入 Vite 环境或浏览器。

相关需求：AUTH-02、DATA-01、MERCHANT-01/02、COUPON-01/02、QUEST-01、OPS-01/02/03、FEEDBACK-01、ANALYTICS-01。
