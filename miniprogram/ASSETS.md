# Media Provenance

The client intentionally contains no fabricated Dongba glyphs, merchant photographs,
geographic points, or cultural explanations. Published image and audio URLs come
from the reviewed backend dictionary and merchant records.

A Wikipedia / Wikimedia lookup for an actual Old Town of Lijiang photograph was
attempted on 2026-09-23 and timed out both inside and outside the sandbox. No image
was downloaded, licensed, or included from that request.

The native WeChat map supplies licensed map imagery under the publisher's WeChat
service terms. The app renders only actual API coordinates and explicitly handles
missing locations.

The Chinese character "迹" used for profile and stamp decoration is a normal
Chinese label, not a claimed Dongba glyph. Camera framing and interface shapes are
ordinary UI affordances.

The three PNG map markers in assets/ are original neutral UI markers generated
by tools/generate_assets.py. They distinguish cultural places, merchants and
quest points by color; none represents a Dongba character.

The backend poster renderer uses approved uploaded glyph images. Its output
reports whether a real WeChat mini-program code was generated; the client does
not draw substitute QR codes. The publisher must confirm usage rights for the
supplied Lijiang background before final design acceptance.

## Homepage reference alignment (2026-09-27; MINI-01, DESIGN-01)

- `assets/home/landscape.jpg` is a compressed derivative of the user-supplied
  `assets/lijiang-home-background.png`. The two original full-size source PNGs
  remain in the workspace and are excluded from the mini-program package.
  No third-party photograph was fetched for this change.
- The shipped background is 179,457 bytes (1125 × 954, JPEG quality 72), down
  from 291,725 bytes. `node miniprogram/tools/generate-home-assets.cjs --landscape-only`
  rebuilds only this derivative from the untouched source. The encoder targets
  at most 190,000 bytes; the homepage test enforces the stricter-than-200-KiB
  200,000-byte resource limit and confirms that the original PNG stays excluded.
- `assets/home/` interface icons, paper texture, decorative mountain landscape,
  and `assets/tabs/` icons are local vector/procedural UI artwork generated by
  `tools/generate-home-assets.cjs`; none is a Dongba glyph or cultural explanation.
- `assets/home/brand.png` rasterizes the ordinary Chinese product wordmark with
  the local Windows STXINGKA font. The font file itself is not bundled.
- Published API records remain the source of dictionary glyphs, categories,
  summaries, and merchant photographs. Browser layout fixtures are explicitly
  marked examples and do not establish cultural authenticity or real-world data.
