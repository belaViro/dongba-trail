# 东巴寻迹 · 丽江微信小程序

原生微信小程序，18 个实际业务页面。所有业务读取后端接口，不内置游客账号、
模拟识别结果、虚构东巴字形、商户或坐标。当前代码可以导入微信开发者工具；
真实登录、识别和正式真机验收仍需项目方配置及经审核内容。

## 启动

1. 启动仓库 FastAPI 服务，默认地址 `http://127.0.0.1:8010`。
2. 微信开发者工具导入本目录。将 `project.config.json` 的
   `appid: "touristappid"` 替换为自己的真实小程序 AppID。
   AppID 是公开标识；AppSecret 和模型密钥只放后端环境配置。
3. 在 `config.js` 设置 `apiBase`。开发者工具访问本机使用默认地址；
   真机不能通过 `127.0.0.1` 访问电脑，须改为可访问的测试 HTTPS 域名。
4. 微信后台配置 request、uploadFile、downloadFile 合法域名和所用媒体域名；
   配置隐私保护指引中的相机、相册、定位和保存图片用途。
   本地工具调试若需临时关闭域名校验，仅在工具个人设置修改；
   项目提交配置保持 `urlCheck: true`。
5. 后端配置微信 AppID/AppSecret、正式隐私指引版本/内容/发布状态/联系信息。
   模型供应商按后端可替换接口配置；未配置时识别显示不可用。
6. 通过运营后台录入并发布审核后的词条、字形图片、商户、POI、优惠券及路线。

无需 npm 安装或构建。开发者工具直接编译 JS/WXML/WXSS。

## 页面与需求

| 页面 | 需求 |
| --- | --- |
| 首页、相机、结果 | MINI-01、AI-03、FEEDBACK-01 |
| 微信登录、隐私指引 | AUTH-01、PRIVACY-01 |
| 文化详情、音频、变体图 | CONTENT-01 |
| 文化商户、商户详情、丽江好物 | MERCHANT-01、REC-01 |
| 文化地图、真实位置导航 | GEO-01 |
| 我的优惠券、核销码 | COUPON-01、COUPON-02 游客入口 |
| 寻迹路线、节点验证、集章 | QUEST-01、QUEST-02 |
| 个人中心、收藏、历史、删除 | USER-01 |
| 我的东巴印记海报、保存、好友分享 | SHARE-01 |

相机先取得明确的隐私同意；用户确认后才上传。识别候选最多 5 项，
模型分数标为“参考分数”，不宣称准确概率。未知结果可提交人工复核。
上传图片只在当前页临时预览，后端当前不持久保存原图；历史页保留结果元数据。

任务条件由后端验证。扫码发送真实扫描结果；围栏使用 GCJ-02 定位；
识字发送本人的已确认识别编号；核销提交已使用券记录；人工节点由运营确认。
人工节点弹窗和个人中心均可复制“寻迹编号”，供运营后台填写游客用户编号。
地图只显示后端发布的真实坐标，无数据时不放示例点位。

海报使用后端生成的 PNG 和已审核字形，不绘制假小程序码。
服务端没有分享码时会明确标记，微信“分享好友”仍使用原生分享入口。
优惠券弹层通过带登录凭据的下载请求展示真实二维码，同时保留文字券码复制；
商户可扫码或输入券码核销，客户端不会自行标记已核销。

## 自动检查

在仓库根目录运行：

```powershell
node miniprogram/tests/validate-project.js
node --test miniprogram/tests/*.test.js
.venv\Scripts\python.exe miniprogram/tests/run_business_flow.py
node miniprogram/tests/native-compile.js "D:\engineering_software\微信web开发者工具"
```

受限 Windows 环境若禁止 Node 子进程，可在 Node 22+ 使用
`node --test --experimental-test-isolation=none miniprogram/tests/*.test.js`。

第一项检查 18 个页面的 JS/JSON、路由和 WXML 事件处理器；第二项检查
授权边界、接口失败、反馈请求、任务证据、地理坐标和海报选字边界。
测试里的 token、编号和图片路径是隔离的单元测试输入，绝不注入应用。

HTTP闭环脚本启动独立临时数据库和真实FastAPI服务，运行原生页面控制器的
登录、识别、纠错、文化详情、推荐、领券、二维码、商户核销、五类节点、奖励、地图、
海报生成及历史清理。微信兑换、识别提供方和设备能力使用明确测试替身；
测试退出时关闭服务、清理临时数据库，不访问日常业务数据库。

最后一项调用本机已安装微信开发者工具中的官方WCC/WCSC，检查WXML和WXSS。
工具安装在其他目录时替换命令末尾路径。该检查不上传代码、不要求登录AppID，
不替代微信真机能力或真实识别准确率验收。

地图 PNG 是中性界面标记，源脚本为 `tools/generate_assets.py`；
通过项目 Python 虚拟环境和 Pillow 可重新生成。来源记录见 `ASSETS.md`。
